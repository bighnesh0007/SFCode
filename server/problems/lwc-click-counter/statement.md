Build a `c-click-counter` component.

- A public property **`label`** (default **`Clicks`**).
- A paragraph with class **`count`** showing `{label}: {count}`. The count starts at **0**, e.g. `Clicks: 0`.
- A button with class **`increment`** that adds 1.
- A button with class **`reset`** that sets the count back to 0. It's **disabled** while the count is 0.

Click **Preview** to try it, then **Run tests**.
